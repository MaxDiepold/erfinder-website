PROTOTYP 0.2 · ESP32-C3

ESP Phone Flasher

iPhone → USB-C → Feather RP2040 USB Host → USB-A/C → ESP32-C3

1. Verbindung

RP2040 wird geprüft …

USB-Host-Status wird geladen.

2. Downloadmodus

  1. BOOT am ESP32-C3 gedrückt halten.
  2. RESET kurz drücken.
  3. RESET loslassen.
  4. BOOT loslassen.
  5. Dann synchronisieren.

3. Firmware

Für einen leeren ESP32-C3 eine merged BIN ab 0x0 verwenden. Eine reine Sketch-BIN bei 0x10000 setzt vorhandenen Bootloader und Partitionstabelle voraus.
